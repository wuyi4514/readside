# 首版验收清单

版本：0.1.0-draft · 日期：2026-10-23。

**执行状态：全部未执行。当前没有运行时代码、插件构建或真实网站验收结果。**

每条用例记录环境、前置条件、操作、实际结果和证据。需要本地模型的用例必须在真实 Chrome 上执行，不能只用 provider mock 判通过。

## 0. 执行条件与证据

- M0 引擎验证先于完整开发，具体项目见 [技术规格](TECHNICAL_SPEC.md#11-m0-验证)。
- 至少测试一套全新配置和一套已准备语言包的配置；记录 Chrome 版本、操作系统、硬件、模型可用状态和权限。
- 自动化夹具覆盖确定性逻辑，真实公开网站覆盖真实 DOM、样式和动态交互；两种结果分别记录。
- 真实网站至少包含：一个产品官网（如 Anthropic 的公开页面）、一个长篇英文博客、一个常见 SPA 内容页、X 公开时间线与帖子详情。这里只定义测试样本，未声称已经支持这些网站。
- 每类页面在宽屏、窄桌面宽度、深浅主题与 200% 缩放下抽查；不能用单张截图代替交互验收。
- X 若受登录或网络限制无法验证，记录限制，不能标为通过；完整首版发布须完成可访问的真实 X 验证。
- 公开证据使用独立构造或合法公开样本，移除个人信息、账号凭据、浏览历史和私信。

## A. 自动翻译、开关与权限

| ID | 场景／操作 | 通过条件 |
| --- | --- | --- |
| A01 | 全新安装 | 自动翻译默认关闭；准备和授权前不自动提取网页文字 |
| A02 | 准备后授权所有支持网站并开启，打开新网站 | 不再点击翻译按钮，可见合格英语自动出现中文 |
| A03 | 保持开启，刷新与完整导航 | 自动处理新 document，无旧页面译文残留 |
| A04 | 翻译请求进行中关闭总开关 | 所有可达页面移除插件显示；迟到响应不能重新插入 |
| A05 | 总开关关闭后点“翻译当前页” | 仅主动处理该页；全局设置不改变，其他页不自动处理 |
| A06 | “恢复当前页原文”，随后页面新增英语内容 | 当前 document 保持暂停；刷新或主动翻译后恢复；其他页不受影响 |
| A07 | 网站禁用／始终／跟随全局；再关闭总开关 | 精确符合产品规格优先级；总关闭能压过“始终翻译” |
| A08 | 权限拒绝、仅当前站授权、权限撤销 | 不越权；不把部分授权显示成全站；撤销后停止，无法清理时提示刷新 |
| A09 | 关闭后重新开启，已有多个标签页 | 当前活动页立即处理，其他授权页激活后处理，无需全部刷新 |
| A10 | 浏览器重启与 service worker 休眠 | 设置不丢；恢复自动处理；没有重复译文或永远等待的任务 |

## C. 语言筛选和译文质量

| ID | 场景／操作 | 通过条件 |
| --- | --- | --- |
| C01 | 默认英语，英语长段落 | 被识别后翻译为简体中文 |
| C02 | `html lang=en`，块内为完整法语 | 不自动翻译该法语段，不用整页标记覆盖块级证据 |
| C03 | 同一英文页的完整西语和中文段落 | 都保持原样，无新增译文 |
| C04 | `AI`、`Paris`、年份、账号、URL、emoji | 无足够语境不强猜英文；纯非自然语言内容跳过 |
| C05 | 英文卡片短标题＋可靠英文正文 | 可在同卡片证据下处理标题；不跨卡片继承 |
| C06 | 一个容器混合英语、法语、西语 | 只处理可靠英文句段；无法可靠拆分则跳过混合块 |
| C07 | 无 lang、错误 lang、检测器低置信度 | 保守决策且可解释；不知道的内容不假装已确认 |
| C08 | 将源语言改为法语／西语 | 取消并清除旧结果，只处理新源语言；英语不继续自动翻译 |
| C09 | 不支持的源语言方向 | 选择前显示不可用原因，不保存一个静默无效选项 |
| C10 | 快速连续切换源语言 | 只保留最终设置方向的译文，旧响应不回写 |
| C11 | 目标选择器、缓存与输出检查 | 首版只有简体中文；无繁简方向串用或旧方向缓存命中 |
| C12 | 含品牌、版本号、日期、价格、百分比的英语 | 人工核对无数值事实改变、型号误改和凭空补充 |
| C13 | 否定、条件、代词、习语和长句 | 人工记录语义可理解程度、漏译和误译，不能只看输出存在 |

语言评估集：独立的 200 个带标注块，英语长段／短标题 80，法语 30，西语 30，中文 20，混合语言 20，歧义短文本与非自然语言 20。校准集与最终验收集分开，不反复调同一套题。

首版目标：在未用于调参的集合中，明确法／西／中文负样本误翻为 0；明确英语长段翻译覆盖 ≥ 95%。歧义短文本允许 unknown 并报告跳过率，不纳入长段覆盖分母。这些是本测试集的准入条件，不代表所有网页零误判。

译文质量另选至少 50 条英语句段，包含 ≥ 20 条数字／型号事实和 ≥ 10 条否定／条件句。人工记录严重语义错误与可接受率；目标无数字事实错误、无意义反转，至少 90% 可理解且不改变核心含义。不通过则暂缓发布或修订引擎方案。

| D10 | X 结构不再符合适配器 | 安全跳过并给兼容状态，不误翻私信／草稿，不翻整个 article |

## 发布判定

M0 闭环通过，所有必需用例通过，性能／质量门槛满足，真实网站证据齐备，才可发布测试版。允许发布说明列出明确的非核心边界；不能把自动翻译不工作、译文错配、破坏组件或上传正文等缺陷归入普通“已知问题”后宣称完成。

需留给使用者复核的重点：参考卡片的真实译文密度、浅色与小字号的舒适度、X 连续阅读和词句查译。自动测试不能代替这些体验判断。
