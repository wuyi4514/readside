# 使用指南

## 对照阅读

Readside 在原文下方追加译文。标题和正文分别对应，原文、强调、链接和网站交互保持可用。

动态加载的评论、列表和信息流会被持续识别，进入当前屏幕及其下方约一屏范围后处理。已显示内容被更新时，旧译文会随之替换；无需再次点击翻译。页面位于后台时暂停新的翻译工作。

对限制显示行数的标题和正文，Readside 保留原网页的截断样式，在有安全空间的位置紧邻显示译文。固定空间不足时保留原布局，可改用选词查译。

## 弹窗操作

| 控件 | 功能 |
| --- | --- |
| 自动翻译 | 开启或关闭自动处理；关闭后清理可达网页中的 Readside 译文 |
| 翻译服务 | 选择 Chrome 本地翻译、Google 或 Microsoft |
| 源语言 | 多选需要翻译的语言，至少保留一种 |
| 目标语言 | 选择译文语言 |
| 翻译当前页 | 主动翻译当前页，自动翻译关闭时也可使用 |
| 恢复原文 | 移除当前页译文，并在本次文档中暂停自动翻译 |
| 允许此网站自动翻译 | 在部分网站范围下，为当前网站添加授权 |
| 选词查译 | 开启或关闭选择文字后的查译入口 |
| 设置图标 | 打开语言包、访问范围、字号等设置 |

“恢复原文”只影响当前页。刷新、完整导航或主动点击“翻译当前页”后，可重新开始翻译。

## 语言与语言包

源语言与目标语言均提供英语、法语、西班牙语、德语、日语、韩语和简体中文。默认只翻译英语到简体中文。

源语言用于筛选内容，并不把整页文字强行当成某种语言。例如只选择英语时，同页法语与中文段落会保留原样。

切换语言或翻译服务后，Readside 会移除旧译文，按新方向重新处理。本地模式下每个方向分别检查和准备；某个方向不可用时，其他已就绪方向仍可使用。Google、Microsoft 在线模式不显示语言包，无需准备，待翻译文本会发送至所选服务。

准备区域采用两列布局，卡片显示完整翻译方向。点击“准备”后，已有模型由浏览器复用，缺少时按需下载。准备期间显示等待圆环，实际下载时显示真实进度与百分比；可取消单项准备或在失败后重试。

切换目标语言不会由 Readside 删除旧模型。Chrome 会隐藏部分缓存状态，因此“待准备”也可能只需初始化新方向。

### 为什么切换目标后又显示“待准备”

“英语→简体中文”与“英语→西班牙语”是两个翻译方向，需要分别准备。已有资源由 Chrome 管理并复用，“待准备”不等同于重新下载源语言模型。

## 选择词句查译

1. 在网页中选择单词、短语或句子。
2. 点击出现的“查译”按钮。
3. 查看原文与译文，按需复制内容。

无法确定源语言时，可手动选择按哪种已选语言查译。按 Esc、点击外部、滚动或切换焦点可关闭面板。

查译提供机器翻译，不提供独立词典释义、发音或语法讲解。

## 版本更新

浏览器运行时，Readside 每天自动检查一次 GitHub 正式 Release；启动或打开插件界面时会补查已到期的检查。新版本提醒显示在弹窗和设置页，提供“下载更新”“更新说明”和“稍后”。

“稍后”将当前版本的提醒隐藏 24 小时；有更新的正式版本时会重新显示。设置页的“检查更新”可主动检查并重新显示已暂缓的提醒。检查失败时保留上次发现的版本，网络恢复后自动重试。

安装包仅在点击下载后保存。按照[安装指南](INSTALL.md#更新)覆盖原目录、重新加载插件并刷新网页即可。

## 阅读设置

译文最小字号可选择 12、14 或 16 px。正文译文通常小于原文，大标题与引用的译文采用更克制的字号；界面跟随系统明暗主题。

已设置的网站会出现在设置页中，可随时移除。没有记录时，该区域自动隐藏。“清除翻译缓存”会清理可达网页中的内存缓存，不会删除浏览器模型。

## 常见问题

### 部分内容没有译文

请检查是否选择了对应源语言，本地模式下还需检查该方向是否就绪；在线模式下请检查服务访问权限与网络。短标题、品牌名或混合语言内容可能无法可靠识别。

导航、按钮、侧栏、列表和表格中的可见文字也参与扫描；紧凑控件随文显示译文。裁切区和空间不足的组件优先保持布局，可选择词句查译。图片、视频和没有可读文字节点的区域不会自动翻译。

### 自动翻译没有开始

请检查自动翻译开关、网站访问范围和 Chrome 权限。若当前页曾恢复原文，可点击“翻译当前页”重新开始。更新插件后，请刷新原网页。

### 语言包无法准备

请使用支持内置翻译能力的桌面 Chrome，并检查网络、存储空间与浏览器管理策略。设置页会显示当前语言方向的可用状态。

### 下载完成后是否还需要联网

本地模式下文字翻译在本机执行；Google、Microsoft 模式需要联网。Readside 不提供项目服务器。模型的下载、更新与清理由 Chrome 管理；浏览器清理模型后可能需要重新准备。

### 能否与其他网页翻译插件一起使用

建议同一页面仅启用一种自动网页翻译功能，避免重复译文和排版冲突。Readside 不移除其他插件插入的内容。
