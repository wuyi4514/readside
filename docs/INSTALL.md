# 安装与使用

当前版本为开发预览版 `0.1.1-preview.2`，适合先在自己的常用网站上试用。正式首版的完整验收仍在推进，详见仓库中的验证报告。

## 安装

1. 下载构建包 `readside-0.1.1-preview.2.zip`，解压到一个准备长期保留的目录。
2. 在桌面 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的目录**。
4. 在 Chrome 的扩展菜单中固定“伴读 · Readside”，方便使用。

不要移动或删除已加载的目录。GitHub 的 “Source code” ZIP 是源代码，需要构建，不能直接当作插件安装包。

## 更新已有安装

解压新构建包，用其中内容替换原插件目录里的文件，在 `chrome://extensions` 点击该插件的“重新加载”，再刷新已经打开的网页。保持原来的目录路径可保留扩展身份和设置，无需另装一份。

## 第一次使用

1. 点击插件图标，打开“设置”。
2. 保持源语言为英语，点击“下载语言包”。首次下载可能需要数分钟；请保持准备页打开，完成后会显示试译结果。
3. 将“自动翻译网页”设为“开启”，将“在所有网站自动翻译”设为“是”，在 Chrome 的原生提示中允许访问。
4. 打开普通英文网页，即可看到原文下方的简体中文译文。

只想在部分网站使用时，将“在所有网站自动翻译”设为“否”，打开需要翻译的网页，在插件弹窗中点击“允许此网站自动翻译”。没有单独设置的网站时，设置页不会显示空的网站列表。拒绝访问权限后，仍可点击“翻译当前页”主动处理当前页。

选择“否”会停止全部网站范围的自动处理并尝试撤销宽泛访问权限；已单独允许的网站可能需要重新点击授权。Chrome 中间的权限确认框由浏览器绘制，插件不能修改它的按钮样式。

## 日常阅读

- **自动对照**：开启后对已授权网站生效；关闭时移除所有可达标签页中的插件译文。
- **翻译当前页**：主动处理一次，自动翻译关闭时也能使用。
- **恢复原文**：只恢复当前页，本次文档内暂停自动翻译；刷新或主动翻译后恢复。
- **选择词句后查译**：选择原文，点击“查译”；可复制原文／译文、查看原句参考，用 Esc 关闭。
- **仅翻译此语言**：默认英语。同页其他语言不自动翻译；更换源语言后可能需要准备对应语言包。
- **阅读样式**：可选择译文最小字号 12／14／16 px，适配明暗主题。

## 当前边界

- 使用桌面 Chrome 的本地翻译能力；API 基线为 Chrome 138+，当前实测环境为 Chrome 155。运行时仍会检查设备、策略和语言方向是否可用。
- 首版主要支持 HTTPS 网页；`chrome://`、扩展商店、PDF、图片和视频不在支持范围。
- 为保护布局，紧凑按钮、导航、裁切区等可能只提供选择查译，不强行增加一行。
- 不按网站域名、URL 路由或私有标记识别内容。复杂 Canvas、封闭 Shadow DOM、没有可读 DOM 的区域不会自动翻译。
- 没有一种通用 DOM 规则能判断所有私密页面。表单、编辑器、隐藏内容和标准聊天日志区域已排除；你可为敏感网站关闭自动翻译。默认正文只在本地处理。
- 更新插件后，请刷新已经打开的网页。移除扩展后刷新网页，可清理尚在显示的旧译文。

本插件不需要 API Key，也不会在本地不可用时自动改用云服务。
