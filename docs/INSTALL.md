# 安装指南

## 环境要求

- 桌面版 Google Chrome 138 或更高版本。
- 本地模式要求设备与浏览器策略允许使用 Chrome 内置翻译能力；在线模式要求可连接 Google 或 Microsoft。
- 首次准备语言包时需要网络连接和足够的本地存储空间。

## 安装 Readside

1. 打开 [Releases](https://github.com/wuyi4514/readside/releases/latest)。
2. 下载 `readside-0.3.0.zip`，解压到准备长期保留的目录。
3. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的目录。
5. 在 Chrome 扩展菜单中固定 Readside。

GitHub 的 Source code 压缩包是源代码；安装时请使用名称以 `readside-` 开头的分发 ZIP。加载后请保留原目录的位置和文件。

## 选择翻译服务

在设置或弹窗中选择 Chrome 本地翻译、Google 或 Microsoft。在线服务会请求对应主机的访问权限，并接收待翻译的文本，不需要下载语言包或填写 API Key。服务使用公开网页端点，可能受网络或服务商限流影响。

## 准备本地翻译方向

1. 点击 Readside 图标，再点击设置图标。
2. 选择源语言与目标语言。源语言可多选，目标语言选择一种。
3. 找到对应的“源语言 → 目标语言”卡片，点击“准备”。已有模型由浏览器复用，缺少时按需下载。
4. 准备时可点击 × 取消；实际下载时，圆环显示浏览器提供的进度。
5. 显示“已就绪”后，即可使用该方向的本地翻译。

默认方向为英语→简体中文。切换目标后，卡片显示新方向的准备状态；“待准备”不代表旧模型被删除或一定需要重新下载。语言识别由所有方向共用，与目标相同的源语言显示“无需翻译”。

准备期间请保持设置页打开。Chrome 负责模型下载与存储，Readside 不需要 API Key。

## 设置自动翻译

将“自动翻译网页”设为“开启”，再选择网站范围：

| 范围 | 设置方法 |
| --- | --- |
| 所有网站 | 将“在所有网站自动翻译”设为“是”，并允许 Chrome 提示的网站访问权限 |
| 部分网站 | 选择“否”，打开需要翻译的网页，在 Readside 弹窗中点击“允许此网站自动翻译” |

也可以保持自动翻译关闭，通过弹窗中的“翻译当前页”按需阅读。

## 更新

1. 下载并解压新版本。
2. 用新文件替换原插件目录的内容。
3. 在 `chrome://extensions` 中点击 Readside 的重新加载按钮。
4. 刷新已经打开的网页。

保持原目录路径可保留扩展身份和设置。更新后打开设置，查看所选语言方向是否需要准备语言包。

## 卸载

在 `chrome://extensions` 中移除 Readside，并刷新已打开的网页。扩展设置随卸载移除；Chrome 管理的共享模型由浏览器自行管理。

更多操作见[使用指南](https://github.com/wuyi4514/readside/blob/main/docs/USAGE.md)。
