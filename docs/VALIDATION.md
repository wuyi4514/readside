# 开发预览验证记录

版本：`0.1.0-preview.1` · 日期：2026-10-23。**有限范围已验证，完整71项验收清单尚未逐条完成。**

## 环境与可复查入口

- Apple M3，macOS 14.4，Google Chrome 155.0.8059.85。
- 独立 Chrome 测试 profile，无 AI 实验 flags，无其他翻译插件；未读取个人 Chrome 配置或登录态。
- Node.js 24.14.0 / npm 11.9.0，锁定依赖，`npm ci` 安装。
- `npm run check`：类型检查、**18项单元测试**和实际扩展构建通过。
- `npm run test:browser`：真实本地模型完成**24项浏览器检查**。逐项结果见[browser-checks.json](validation/browser-checks.json)。其中耗时是每项测试流程耗时，不能作为翻译 p95 指标。

## 本地模型闭环

在扩展准备页真实点击下载 Translator / LanguageDetector 语言包，观察实际进度并成功试译。关闭准备页后，两个此前未访问的 HTTPS origin 在没有页面激活的情况下完成自动翻译；严格 CSP 的安全 localhost 夹具同样可用。重启 Chrome 后工具重新载入扩展，无需重新下载或点击模型准备。完整说明及自动化安装方式的限制见[引擎验证](ENGINE_SPIKE.md)。

## 24项真实浏览器检查覆盖

| 覆盖 | 检查内容 |
| --- | --- |
| 准备与自动运行 | 已下载模型可用、设置持久化、严格 CSP 自动真实翻译 |
| 对照与语言 | 卡片标题／正文分别对应，英语翻译，法语／西语／中文与排除区域保留 |
| DOM 与布局 | 原始文本／强调／链接保留，深色纯色背景对比度≥4.5，窄桌面无新增横向溢出 |
| 动态内容 | 新增段落、原文替换、主帖与引用分离、200次同步节点复用后仅显示最终结果 |
| 通用兼容 | 改为自定义标签并更换无关属性后仍能提取；没有网站专用标记依赖 |
| 学习与无障碍 | 真实单词本地查译与 Esc 关闭，整卡链接原可访问名称保留 |
| 生命周期 | 恢复当前页并暂停新增内容，总关闭清理多个文档，关闭后主动翻译，worker 终止后恢复 |
| 实际 Popup | Chrome action 打开的真实弹窗正确定位当前页；恢复、翻译、关闭与重新开启有效 |

单测另有不可取消 provider 的迟到结果、换文错配和旧请求未返回时重新启动的回归；这些测试明确使用替身验证并发合同，不冒充模型结果。

浏览器回归使用与发布构建相同的运行时 JS，**测试 manifest 预先授予网站权限**，以隔离 Chrome 原生授权提示。因此这些通过结果不包含正常安装后的权限允许／拒绝流程验收。真实 Popup 操作通过 CDP 连接实际 action 页面，未以普通标签页模拟当前页。

## 分发与隐私检查

安装 ZIP 只包含构建文件、图标、安装说明、隐私说明和 MIT，不含源码开发依赖、测试 profile、私有证据、用户附件或密钥。根目录直接含 manifest，附 SHA-256。

源码使用浏览器本地 API，没有 fetch／XHR／WebSocket／远程脚本或正文上传逻辑；扩展页面 connect-src 为 none。夹具运行时请求记录只有本地扩展资源和夹具资源。该观察不等于对 Chrome 自身模型下载流量的完整审计。

## 仍需完成的正式首版验收

- 正常通过 Chrome UI 安装后跨完整重启、实际权限允许／拒绝／撤销流程，以及离线、包清理、策略禁用和下载取消恢复。
- 独立标注语言语料、50条质量样例及其他源语言方向的质量验证；短标题可能保守跳过。
- 100段、20次独立测量的首块／关闭 p50与p95、长任务和持续内存分析；200次同步复用并不等于完整压力验收。
- 各站真实 SPA 导航／返回／长帖展开、更多视口、200%缩放和屏幕阅读器；其他系统与 Chrome 版本。
- 图片／渐变／透明背景和高级色彩空间的稳定对比度；任意网站、iframe 和 Shadow DOM 的覆盖不作保证。
- 用户对译文密度、字号、配色和英语学习体验的实际反馈。

本预览可安装试用，但不宣称正式首版的所有兼容性、性能和质量门槛已经通过。完整目标仍按[验收清单](ACCEPTANCE.md)执行。
