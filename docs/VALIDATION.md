# 开发预览验证记录

版本：`0.2.0-preview.3` · 日期：2026-10-23。**有限范围已验证，完整71项验收清单尚未逐条完成。**

## 环境与可复查入口

- Apple M3，macOS 14.4，Google Chrome 155.0.8059.85。
- 独立 Chrome 测试 profile，无 AI 实验 flags，无其他翻译插件；未读取个人 Chrome 配置或登录态。
- Node.js 24.14.0 / npm 11.9.0，锁定依赖，`npm ci` 安装。
- `npm run check`：类型检查、**35项单元测试**和实际扩展构建通过。
- `npm run test:browser`：真实本地模型完成**42项浏览器检查**。逐项结果见[browser-checks.json](validation/browser-checks.json)。其中耗时是每项测试流程耗时，不能作为翻译 p95 指标。

## 本地模型闭环

0.2.0 使用扩展来源的 offscreen Window + 实际专用 Worker；纯文本只经本扩展内部 RPC 送往本机模型。该变更解决多语言在新网站上逐方向 create 的用户激活限制。早期仅英语的 M0 记录不能外推全部语言。六种源语言→简体中文已实际执行，并验证设置页关闭后新 HTTPS origin 自动运行。

全新 profile 中的 en／fr／es／de／ja／ko 模型准备均使用真实点击和 native monitor；每个方向分别记录66／48／67／69／70／74个不同进度值，从0到1。[下载事件证据](validation/model-downloads.json)。这些不是按定时器模拟的进度。最终圆环版另在一个新 profile 完成实际下载、取消与重试；共用检测包在该测试中也走实际准备流程，但其首次进度未单独记录。逐语言质量尚未打分。


早期 M0 在扩展准备页真实点击下载 Translator / LanguageDetector 语言包，观察实际进度并成功试译。关闭准备页后，两个此前未访问的 HTTPS origin 在没有页面激活的情况下完成自动翻译；严格 CSP 的安全 localhost 夹具同样可用。重启 Chrome 后工具重新载入扩展，无需重新下载或点击模型准备。完整说明及自动化安装方式的限制见[引擎验证](ENGINE_SPIKE.md)。

## 42项真实浏览器检查覆盖

| 覆盖 | 检查内容 |
| --- | --- |
| 准备与自动运行 | 已下载模型可用、设置持久化、严格 CSP 自动真实翻译 |
| 对照与语言 | 卡片标题／正文分别对应，英语翻译，法语／西语／中文与排除区域保留 |
| DOM 与布局 | 原始文本／强调／链接保留，新增不翻译／编辑器／控件标记会清理已有译文，局部语言证据变化后重新判断，深色纯色背景对比度≥4.5，窄桌面无新增横向溢出 |
| 动态内容 | 新增段落、原文替换、主帖与引用分离、200次同步节点复用后仅显示最终结果 |
| 通用兼容 | 改为自定义标签仍能提取；轮播卡片部分超出视口时仍翻译、布局展开后重试、纵向文字标题完整提取；没有网站专用标记依赖 |
| 学习与无障碍 | 真实单词本地查译与 Esc 关闭，整卡链接原可访问名称保留 |
| 生命周期 | 恢复当前页并暂停新增内容，总关闭清理多个文档，关闭后主动翻译，worker 终止后恢复 |
| 设置与授权范围 | 空网站区隐藏；部分网站模式下即使浏览器有宽泛测试权限也不自动处理；允许当前网站后生效，删除最后记录后区域消失 |
| 多语言与控件 | Readside英文品牌、自定义下拉框／radio、六种源语言多选与独立语言包、中文源语言、紧凑两列布局、字号键盘选择、目标切换到英／日／法及输出lang更新 |
| 实际 Popup | Chrome action 打开的真实弹窗正确定位当前页；恢复、翻译、关闭与重新开启有效 |

单测另有不可取消 provider 的迟到结果、换文错配和旧请求未返回时重新启动的回归；这些测试明确使用替身验证并发合同，不冒充模型结果。本轮增加设置迁移、多语言按句路由、缺包方向隔离、浏览器缓存状态／激活合同和受信 RPC／连接前取消检查。另有4项设置合同测试：权限请求在输入事件内直接发起、拒绝后不保存并回滚单选、先收窄范围再撤销权限、点击已选择的“是”可重新授权。

浏览器回归使用与发布构建相同的运行时 JS，**测试 manifest 预先授予网站权限**，以隔离 Chrome 原生授权提示。因此这些通过结果不包含正常安装后的权限允许／拒绝流程验收。真实 Popup 操作通过 CDP 连接实际 action 页面，未以普通标签页模拟当前页。

## 真实公开网页观察

没有页面内容 mock，也没有网站适配器。前四项保留0.1.1预览的历史现场观察，通用提取策略仍沿用；Granola 为本轮0.2.0引擎的复测。首屏附近的单次观察如下，原始结构数据见[live-pages.json](validation/live-pages.json)。

| 页面 | 观察结果 |
| --- | --- |
| [Anthropic News](https://www.anthropic.com/news) | 6块出现译文，观察时无横向溢出 |
| [Josh W. Comeau 英文博客](https://www.joshwcomeau.com/css/interactive-guide-to-flexbox/) | 2块出现译文，观察时无横向溢出 |

这些数量不是整页覆盖率或翻译质量分数，会随网站更新、视口和加载时机变化。X 使用公开未登录页面，没有执行发帖、点赞或关注。动态节点压力来自独立夹具，不能推定全部真实信息流交互已通过。

本轮 Granola 运行中，51次实际 chrome.action.setIcon 调用成功，其中49次使用16／32／48尺寸工作环；未用替身替代原生图标 API。

README 截图来自本插件实际设置页，弹窗截图也来自 Chrome action 的真实页面；三列卡片样例为原创夹具。未公开用户附件、个人浏览配置或私人页面截图。

## 分发与隐私检查

安装 ZIP 只包含构建文件、图标、安装说明、隐私说明和 MIT，不含源码开发依赖、测试 profile、私有证据、用户附件或密钥。根目录直接含 manifest，附 SHA-256。

源码使用浏览器本地 API，没有 fetch／XHR／WebSocket／远程脚本或正文上传逻辑；扩展页面 connect-src 为 none。夹具运行时请求记录只有本地扩展资源和夹具资源。该观察不等于对 Chrome 自身模型下载流量的完整审计。

## 仍需完成的正式首版验收

- 正常通过 Chrome UI 安装后跨完整重启、实际权限允许／拒绝／撤销流程，以及离线、包清理和策略禁用。圆环下载的取消／重试已在新 profile 实测，完整浏览器关闭后的恢复仍需补齐。
- 独立标注语言语料、50条质量样例及全部语言方向的质量验证；目前真实回归不代表42种非同语方向全部已验收，短标题仍可能保守跳过。
- 100段、20次独立测量的首块／关闭 p50与p95、长任务和持续内存分析；200次同步复用并不等于完整压力验收。
- 各站真实 SPA 导航／返回／长帖展开、更多视口、200%缩放和屏幕阅读器；其他系统与 Chrome 版本。
- 图片／渐变／透明背景和高级色彩空间的稳定对比度；任意网站、iframe 和 Shadow DOM 的覆盖不作保证。
- 用户对译文密度、字号、配色和英语学习体验的实际反馈。

本预览可安装试用，但不宣称正式首版的所有兼容性、性能和质量门槛已经通过。完整目标仍按[验收清单](ACCEPTANCE.md)执行。
