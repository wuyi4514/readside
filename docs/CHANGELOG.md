# 版本记录

版本遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。

## 0.3.1 — 2026-10-26

- 修复完整句子或跨段落选区因源码换行与显示空白不同而无法查译的问题。
- 优化主动查译的语言判断，保留自动翻译的严格语言筛选。

## 0.3.0 — 2026-10-24

- 新增 Google、Microsoft 在线翻译，可在弹窗和设置中切换，无需准备语言包。
- 扩大全页扫描范围，覆盖导航、按钮、侧栏、短文本和表格，持续处理动态加载内容。
- 紧凑区域采用随文译文，保留原文和点击交互。
- 移除词句查译中的“查看原句参考”。
- 更新翻译服务授权、隐私说明和使用指南。

## 0.2.5 — 2026-10-24

- 改善限制显示行数的标题和评论的对照展示，保留网页原有截断样式。
- 修正半透明背景上的译文颜色，并随 hover、焦点和颜色过渡更新。
- 改善懒加载及内联文字更新的识别，及时替换旧译文。

## 0.2.4 — 2026-10-24

- 翻译卡片显示完整的“源语言 → 目标语言”，提供明确的“准备”按钮。
- 区分检查、待准备、准备中与下载进度，避免将浏览器的缓存隐藏状态误报为需要重新下载。
- 切换目标时停止旧任务，保留真实进度与取消、重试交互。
- 设置页示例更新为 Anthropic 的长期运行应用开发研究文章，并同步来源链接。

## 0.2.3 — 2026-10-24

- GitHub 仓库统一更名为 `readside`。
- 更新项目首页徽章、克隆命令、下载入口、问题反馈和设置页链接。
- 补全软件包与扩展的项目主页信息。

## 0.2.2 — 2026-10-24

- 设置页使用真实网页的对照翻译截图，配合简短产品介绍。
- 支持点击截图放大查看，并提供原网页来源链接。
- 效果图随插件打包，设置页无需加载外部图片。

## 0.2.1 — 2026-10-23

### 功能

- 在网页原文下方显示译文，支持动态加载内容和选择词句查译。
- 源语言多选，目标语言单选，提供英语、法语、西班牙语、德语、日语、韩语和简体中文。
- 浏览器本地翻译，无需 API Key；语言包采用两列布局、圆环进度和独立下载、取消、重试。
- 提供自动翻译、网站范围、恢复原文和译文最小字号设置。

### 界面与文档

- 设置页采用简洁的双语阅读示例，优化左侧排版和深色模式。
- 语言选择器使用 SVG 勾选标记，使对钩与复选框居中对齐。
- 统一扩展版本和安装包命名，发布 `readside-0.2.1.zip`。
- 重新组织项目首页、安装与使用指南、隐私说明、贡献指南及产品和技术文档。
