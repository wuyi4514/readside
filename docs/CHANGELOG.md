# 版本记录

## 0.2.0-preview.3 · Readside

- 设置、弹窗、扩展名称统一为 Readside；重新用 imagegen 制作蓝色字母 Logo。
- 源语言可多选英／法／西／德／日／韩／简体中文；目标从相同集合单选。
- 自定义下拉框和 radio，支持键盘；删除顶部设置文字。
- 语言包改为两列紧凑布局、真实圆环进度，支持独立取消／重试；缺包不阻断其他方向。
- 多语言本地引擎移至扩展 offscreen Window，Worker 对任务排队与取消，解决新网站逐方向激活限制。正文仍不出浏览器本机。
- 工具栏工作环和清楚的状态提示，去掉方形文字徽标。

## 0.1.1-preview.2 · 伴读 Readside

- 横向轮播按原文容器边界判断插入位置，不再因卡片暂时超出视口而漏翻。
- 因布局保护跳过的内容，在容器展开、字体尺寸或布局改变后重评估；支持纵向文字标题。
- 大字号引用的译文缩小至最多18px，保持原文主导。
- 重做弹窗与设置页：黑白灰界面、统一文字层级，自动翻译和网站范围采用原生单选项。
- 删除宣传标语与空的网站设置，添加允许网站后才显示对应记录。
- 名称改为伴读 · Readside，图标用内置 imagegen 生成，源图和提示词见 assets/。

仍为开发预览，完整验收状态见 VALIDATION.md。仓库地址保留以延续已有下载和源码链接。
