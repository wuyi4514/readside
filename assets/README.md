# 品牌资源

Readside 使用蓝色圆角方形和白色小写字母 r 作为产品图标，品牌名称统一写作 **Readside**。

## 文件

| 文件 | 用途 |
| --- | --- |
| `readside-logo.png` | 透明背景的图标源图 |
| `icons/16.png` | 浏览器工具栏小尺寸 |
| `icons/32.png` | 浏览器工具栏高分辨率尺寸 |
| `icons/48.png` | 扩展列表、弹窗和设置页 |
| `icons/128.png` | 扩展详情与分发资源 |

## 使用方式

图标保留原始比例和透明背景，不拉伸、不添加描边、不改变字母与底板的相对位置。产品界面中的图标应与 Readside 名称保持适当间距。

品牌蓝为 `#3266E8`，图标字母为白色。浅色和深色界面均使用同一图标。

源图由 OpenAI ImageGen 生成；各尺寸图标从同一源图导出。资源随项目按 [MIT 许可证](../LICENSE) 分发。
